PROJECTS

MSA 기반 커뮤니티 서비스 플랫폼 구축 (SSAFY 자율 프로젝트)

2023.04 - 2023.05
[프로젝트 요약]

Spring Boot 기반의 여러 마이크로서비스로 구성된 커뮤니티 서비스를 개발하고, 이를 AWS EKS 환경에 배포 및 운영했습니다. 백엔드 개발 과정에서 마주친 복잡한 배포, 비효율적인 리소스 관리, 잦은 환경 설정 오류 등의 문제를 해결하기 위해 직접 DevOps 파이프라인과 클라우드 네이티브 인프라를 구축했습니다.

[My Role & Key Achievements]
• GitOps 워크플로우 확립을 통한 개발 문화 개선
  • Argo CD와 Helm을 도입하여, Git 저장소를 '단일 진실 공급원(Single Source of Truth)'으로 사용하는 GitOps 환경을 구축했습니다.
  • git commit 이력을 통해 모든 인프라 및 애플리케이션의 변경사항을 추적하고, 문제 발생 시 특정 시점으로 롤백할 수 있는 안정적인 운영 기반을 마련했습니다.
  • 개발자가 익숙한 Git 플로우만으로 배포, 스케일링, DNS 설정까지 직접 처리할 수 있는 셀프 서비스(Self-service) 환경을 제공하여, 팀의 전체 개발 속도와 생산성을 향상시켰습니다.
• 모니터링 시스템 구축을 통한 애플리케이션 성능 분석 및 안정성 확보
  • Prometheus와 Grafana를 연동하여 각 마이크로서비스의 CPU/Memory 사용량, HTTP 요청 수, Latency 등 핵심 성능 지표(Metric)를 시각화했습니다.
  • Alertmanager와 Slack을 연동하여 리소스 임계치 초과 등 장애 징후를 사전에 감지하고 대응할 수 있는 자동 알림 시스템을 구축했습니다.
• 탄력적 인프라 구성을 통한 서비스 확장성 및 비용 효율성 개선
  • HPA와 Karpenter를 적용하여, 부하 테스트로 발생하는 트래픽 양에 따라 백엔드 서비스의 파드와 EC2 노드가 자동으로 확장/축소되도록 구성했습니다.
  • 이를 통해 갑작스러운 트래픽 증가에도 안정적인 서비스를 보장하는 탄력성(Resilience)을 확보하고, 유휴 시간에는 리소스를 최소화하여 클라우드 비용을 최적화했습니다.
• 클라우드 네이티브 네트워킹 및 스토리지 설계
  • Ingress Controller와 ExternalDNS를 연동하여, 새로운 서비스가 추가될 때 Route53에 DNS 레코드가 자동으로 등록되도록 구성하여 MSA 확장성을 확보했습니다.
  • EFS와 PVC를 연동하여 MySQL과 같은 상태 저장(Stateful) 애플리케이션의 데이터 영속성을 보장하도록 설계했습니다.
